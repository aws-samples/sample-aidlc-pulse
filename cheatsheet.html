AI-DLC Commands Cheatsheet

awslabs/aidlc-workflows · v2.11.3 (4 Nov 2026) ← Dashboard
Two command planes. /aidlc ... runs in the agent chat and drives the workflow. aidlc ... runs in your terminal for install, project setup, diagnostics and updates.
Prefix by harness. Type /aidlc on Kiro CLI, Kiro IDE, Claude Code, Cursor, opencode and Copilot. On Codex CLI type $aidlc. Flags are identical.
Plain words work. At any gate or question you can answer in your own words ("approve", "skip market research", "redo this stage"). Flags are the exact form of the same requests.
Click any command to copy it. Use the filter box to narrow the sheet. <x> = required, [x] = optional.

1Install & set upterminal

curl -fsSL https://github.com/awslabs/aidlc-workflows/releases/latest/download/install.sh | shInstall the native aidlc command (macOS / Linux). Adds ~/.local/bin/aidlc.
irm https://github.com/awslabs/aidlc-workflows/releases/latest/download/install.ps1 | iexInstall on Windows PowerShell (normal, non-admin window).
export PATH="$HOME/.local/bin:$PATH"Put aidlc on PATH for this shell.
aidlc configSet up or refresh the current project (interactive: picks or asks for the harness).
aidlc config --harness kiro-ideSet up for a named harness: kiro-ide (Kiro IDE ≥1.1.70, Kiro CLI ≥2.24.1), kiro, claude, codex, cursor, opencode, copilot.
aidlc config --harness claude --dry-runPreview the full plan without changing any files.
aidlc config --yesNon-interactive refresh / confirm.
aidlc doctorHealth check of machine, project and framework integrity.

2Native aidlc commandsterminal

aidlc --helpThe six public commands: config, doctor, version, update, use, uninstall.
aidlc <command> --helpEvery option for one command.
aidlc help --allAlso reveals the hidden engine and system namespaces.
aidlc versionPrint the active version.
aidlc updateInstall the newest release on your channel.
aidlc update --checkCheck only. Exit code 5 = update available.
aidlc update --channel stableSwitch channel and update now.
aidlc config --channel previewFollow the preview stream (stable to go back).
aidlc use <version>Activate an installed version on this machine.
aidlc rollbackGo back to the previously active version.
aidlc config --pin 2.10.0 --yesPin the project to a release (CI / team consistency).
aidlc config --unpinRemove the project pin.
aidlc doctor --verboseExpand every check, healthy rows too.
aidlc doctor --check-updatesHealth check plus refreshed update metadata.
aidlc doctor --export [--output <dir>]Write a redacted diagnostic bundle to share.
aidlc uninstallRemove the machine install (keeps config). --purge --yes also removes machine records.

Shared options: --project-dir <path> --json --quiet --no-color --yes --offline --verbose

4Start workchat

/aidlc <describe the work>Start from a description. The agent proposes a plan (scope) for you to confirm.
/aidlc Read ./vision.md and build what it describesStart from a vision doc (+ technical-environment.md). Read as data.
/aidlc <scope> [description]Start with an explicit scope, e.g. /aidlc feature Add saved searches.
/aidlcResume the open workflow. With no work yet, asks what to build.
/aidlc compose "<task>"Adaptive composer: proposes a tailored EXECUTE/SKIP plan.
/aidlc compose --report <path>Compose a fix-and-ship run from a scan report.
/aidlc --new-scope '<task>'Force a custom plan even when a stock scope fits.
/aidlc-init --scope <name> <description>Create the intent (Initialization phase) in one step, then stop.
/aidlc-init --scope <name>Ask what the work is for, then start it.
/aidlc-composeTypeable shortcut for /aidlc compose.

5Status, resume & navigatechat

/aidlc --statusRead-only progress summary.
/aidlc parkPark at the current stage boundary for later or for another person.
/aidlc --stage <slug|#>Jump to a stage, e.g. --stage code-generation or --stage 3.5. Skipped stages become [S].
/aidlc --phase <name|#>Jump to the start of a phase (ideation, inception, construction, operation).
/aidlc --stage <slug> --singleRun one stage in isolation. Never moves your workflow pointer.
/aidlc --stage <slug> --unit <unit>Re-run a stage for one unit of work.
/aidlc --resume --stage <slug>Resume, targeting a specific stage.
redo this stageSay it in chat: resets and re-runs the current stage (or the active unit's step).
start freshSay it in chat: starts a new intent beside the current one.
/aidlc --version · /aidlc --helpFramework version · usage.
/aidlc --doctor [--check-updates]Health check from inside the session.
/aidlc --doctor --exportFresh check + redacted diagnostic report.

6Change the planchat

/aidlc --scope <name>Change the active scope (or start one on a fresh project).
/aidlc --skip <slug,...>Drop pending stages now, e.g. --skip market-research,team-formation.
/aidlc --add <slug,...>Put stages back on the plan.
/aidlc --depth <minimal|standard|comprehensive>Override artifact depth.
/aidlc --test-strategy <minimal|standard|comprehensive>Override test strategy.
/aidlc --project-type <greenfield|brownfield>New project or existing code. Brownfield mid-run re-scans and runs Reverse Engineering.
/aidlc --review <adversarial|advisory|none>Stage reviewer level for this run (replaces scope cap).
save this plan as quick-fixSay it in chat: keeps the current plan as a reusable scope (aidlc engine scope save).

7Workflow settings & ceremonychat

/aidlc --collaborators <on|off>Bring in support agents, or lead agent only.
/aidlc --statusline <on|off>AI-DLC progress in the status line.

8Intents & spaceschat

/aidlc intent [name]List intents in the active space, or switch to one. --all includes archived.
/aidlc intent archive <name>Retire an intent without deleting its record (unarchive restores).
/aidlc intent add-repo <name> [--url <address>]Add a sibling repo, cloning it if needed (remove-repo takes one out).
/aidlc intent set-repos <name,...>Set exactly which repos the work covers (--all keeps all).
/aidlc intent add-checkout <path>Include code from another worktree in reviews (remove-checkout).
/aidlc space [name]List spaces, or switch to one.
/aidlc space-create <name>New space with the default space's org rules.

9Team units (workshop / mob construction)chat

/aidlc team-board [--snapshot] [--space <n>] [--intent <n>]Read-only board: unit progress, claims, merge readiness.
/aidlc unit statusClaimable, claimed and dependency-blocked units.
/aidlc unit participateMark this clone for the guided unit picker.
/aidlc unit claim <unit> --team "<label>"Claim a unit and bind this checkout. Also --claim <unit> [--rhythm per-stage|unit-end].
/aidlc unit adopt <unit>Adopt a teammate's live claim in a fresh clone.
/aidlc unit release <unit>Release a claim (from unscoped main). Same as --release.
/aidlc unit publish <unit>Team: publish the clean, committed candidate to its claim ref.
/aidlc unit pin <unit>Facilitator, on main: pin and validate the candidate.
/aidlc unit gate <unit> --decision approve --user-input "..."Record the merge decision (approve / reject).
/aidlc unit land <unit> --target mainMerge, fold state and audit. Then git push origin main.
/aidlc unit merge-status <unit>Read the local merge transaction journal.

Flow: facilitator runs Inception as a mob, then teams claim → construct 3.1 to 3.5 → commit → publish; facilitator pins → gates → lands.

11Knowledge (DocumentKB)chat

Put PDFs, Word, Markdown, text under aidlc/spaces/<space>/knowledge/documents/. Also /aidlc-knowledge <verb>; --space <name> targets another space.

/aidlc knowledge onboard [path]Index a file/folder, or sweep all new files.
/aidlc knowledge syncReconcile the catalog with disk; retry extraction.
/aidlc knowledge list [--json]Catalog with each document's state.
/aidlc knowledge show <id>One record plus extracted text.
/aidlc knowledge associate <id> --intent [slug]Scope a document to one intent (dissociate removes).
/aidlc knowledge rebind <id> --to <path>Repair a row whose file moved and changed.
/aidlc knowledge summarize <id> --text-file <p> --source-revision <sha256>Store an LLM-written summary (+ --tags).

16Env vars, exit codes, filesreference

AWS_AIDLC_DEFAULT_SCOPE=featureDefault scope at workflow start.
AIDLC_DISABLE_SENSORS=1Force sensors off (also AIDLC_DISABLE_LEARNINGS, AIDLC_DISABLE_SUMMARY_CONFIRMATION).
AIDLC_UNATTENDED=1Unattended run: refuses plan changes nobody approved.
AIDLC_ALLOW_ROOT=1Allow install as root (containers / CI). Same as --allow-root.
NO_COLOR=1 · FORCE_COLOR=1Disable / force terminal colour.
ExitMeaning
0Success
1Operational failure
2Usage or invalid config
3Network result or runtime unavailable
4Integrity or ownership refusal
5Action required (e.g. update available)
